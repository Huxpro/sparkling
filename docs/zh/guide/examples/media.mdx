# 媒体

Sparkling 的媒体 API 让 Lynx 页面通过原生层选择、上传与下载媒体。以下示例演示
每个流程。

:::tip
访问媒体需要原生桥与设备权限 —— 请使用**二维码**标签页在手机上运行。
:::

## 选择

从设备中选取图片或视频。

<Go
  example="sparkling-go"
  defaultEntryName="media-choose"
  defaultFile="src/pages/media-choose/App.tsx"
  entry="src/pages/media-choose"
/>
