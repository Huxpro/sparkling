# Scheme

Sparkling 使用统一的 URL scheme 打开页面并配置其容器。以下示例可用于构建并
预览 scheme URL。

## 交互式构建器

逐项构建 scheme URL 并实时预览结果。

<Go
  example="sparkling-go"
  defaultEntryName="scheme-builder"
  defaultFile="src/pages/scheme-builder/App.tsx"
  entry="src/pages/scheme-builder"
/>
