# 示例

Sparkling 提供了一组可运行的 Lynx 示例。每个示例都通过
[`<Go>`](https://github.com/lynx-community/go-web) 组件嵌入，你可以：

- **浏览源码** —— 逐个文件阅读完整示例。
- **网页预览** —— 在浏览器中实时运行该 Lynx 页面。
- **扫码上真机** —— 通过二维码在 Lynx Explorer（已集成 Sparkling）中打开，
  真正运行原生能力。

:::tip 网页预览 vs 真机
**网页预览**会在浏览器中运行 UI。得益于 Sparkling 的
[实验性 Web 支持](https://github.com/tiktok/sparkling/pull/22)，部分 method 现在
也有了浏览器实现 —— **导航**（History API）、**存储**（`localStorage`）与
**媒体**（file input / `fetch`），因此这些示例可以直接在此交互。要体验真正的原生
行为，请使用**二维码**标签页，在手机的 Lynx Explorer 中打开示例。
:::

## Sparkling Go 示例

[Sparkling Go playground](https://github.com/tiktok/sparkling/tree/main/packages/playground)
是一个演示全部内置能力的完整应用。其示例按功能分组：

- [**导航**](/zh/guide/examples/navigation) —— 基于 scheme 的 push/pop 与页面间传参。
- [**Scheme**](/zh/guide/examples/scheme) —— 构建并预览 Sparkling scheme URL。
- [**全局属性**](/zh/guide/examples/global-props) —— 读取设备、屏幕与容器信息。
- [**存储**](/zh/guide/examples/storage) —— 持久化并读取键值数据。
- [**媒体**](/zh/guide/examples/media) —— 选择、上传与下载媒体。

## 工作原理

`packages/website/scripts/prepare-examples.mjs` 会把 `examples/*` 下的每个目录
以及 `packages/playground` 应用变成在线嵌入示例：构建每个示例（用于浏览器的
`*.web.bundle` 与用于真机的 `*.lynx.bundle`），写入符合 go-web 规范的
`example-metadata.json`，并复制到 `public/examples/<name>/`。`<Go>` 组件读取该
元数据。
