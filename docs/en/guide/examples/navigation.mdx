# Navigation

Sparkling routes between Lynx pages and native screens with a unified URL
scheme. These demos come from the Sparkling Go playground.

:::tip Web navigation works here
Thanks to Sparkling's [experimental Web support](https://github.com/tiktok/sparkling/pull/22),
navigation runs **live in the Web preview** below — tapping a button swaps the
preview to the target page. The **QR code** tab runs the same flow on device.
:::
