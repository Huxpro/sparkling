# Navigation

Sparkling routes between Lynx pages and native screens with a unified URL
scheme. These demos come from the Sparkling Go playground.

:::tip
Navigation calls the native bridge, so tapping the buttons only navigates inside
a Sparkling container. Use the **QR code** tab to run on device.
:::
